AI-Assisted Cyber & IoT Threat-Detection and Contextual Risk-Prioritization SystemOpen In ColabAn end-to-end AI-Assisted Cyber & IoT Threat-Detection Pipeline and interactive Gradio Security Operations Center (SOC) Web Dashboard that identifies known and unseen zero-day cyber attacks from structured network and IoT telemetry, eliminates false positives through contextual risk scoring and human-in-the-loop active learning, and explains every alert using local SHAP feature attributions.1. Problem Statement & Project MotivationModern Security Operations Centers (SOCs) monitoring enterprise and Internet of Things (IoT) environments face two critical operational failures:Unseen Zero-Day Attacks Evade Static Rules and Supervised ML: Traditional deterministic rules (Sigma SIEM signatures, YARA rules, and static Z-score thresholds) and standalone supervised classifiers only recognize previously labeled attack signatures. Stealthy zero-day attacks—such as low-and-slow covert DNS/TLS data exfiltration or fixed-jitter Command-and-Control (C2) beaconing—keep packet rates and login failures within normal bounds and bypass detection completely.High False-Positive Volume Causes Analyst Alert Fatigue: Routine business-hour traffic surges (08:00–18:00) and scheduled administrative server backups trigger hundreds of false alarms in conventional anomaly detectors. Furthermore, treating an anomaly on a low-impact IoT smart bulb with the same priority as an anomaly on a core Domain Controller overwhelms human analysts.How This System Solves Both ProblemsHybrid Parallel AI Ensemble: Executes a Supervised Gradient-Boosted Decision Tree Classifier (XGBoost / LightGBM) in parallel with an Unsupervised 3-D Subspace Reconstruction Autoencoder and Isolation Forest trained strictly on benign traffic. The supervised branch captures known volumetric DDoS and brute-force attacks with high precision, while the unsupervised branch catches 100.0% of unseen Zero-Day attacks via multivariate covariance distortion.Contextual False-Positive Suppression & Risk Prioritization: Filters raw ensemble probabilities through dynamic diurnal business-hour thresholds, asynchronous VirusTotal and MISP threat-intelligence enrichment, human-in-the-loop active learning feedback, and CMDB asset criticality weighting—achieving 99.72% Overall Accuracy, 97.1% Precision, 100.0% Recall (98.5% F1-Score), and a 96.7% reduction in false positives.2. Four-Stage System Architecture in DetailStage 1: Telemetry Ingestion, Feature Engineering & Leakage-Free ValidationBenchmark & Live Telemetry Sources: Designed for structured network flows and host logs modeled on UNSW-NB15, CICIDS2017, and BoT-IoT, as well as live Zeek (conn.log, dns.log), Suricata (eve.json), and AWS CloudTrail telemetry.Sliding-Window Feature Engineering: Raw connection events are aggregated over 5-second windows into 7 orthogonal features across 3 behavioral dimensions:Behavioral DimensionFeature NameMathematical FormulationSecurity Signal CapturedTemporalflow_duration_ms$\log(1 + t_{\text{end}} - t_{\text{start}})$Separates rapid SYN floods from long-lived covert C2 tunnelsTemporalinter_arrival_ms$\log(1 + \max(0.01, \mu_{\Delta t}))$Detects automated sub-millisecond floods and fixed-jitter C2 beaconsTemporalpkt_rate$\log(1 + N_{\text{pkts}} / (\Delta t_{\text{sec}} + 0.05))$Captures high-velocity UDP/TCP DDoS packet surgesSpatialbyte_ratio$\log(1 + \text{Bytes}_{\text{sent}} / (\text{Bytes}_{\text{recv}} + 1))$Flags asymmetric outbound data exfiltration and DNS tunnelingSpatialbytes_per_pkt$\log(1 + (\text{Bytes}_{\text{sent}} + \text{Bytes}_{\text{recv}}) / N_{\text{pkts}})$Separates small-payload C2/scanning frames from bulk file transfersCategoricaldst_port_entropy$-\sum p(\text{port}_k) \log_2 p(\text{port}_k)$Identifies horizontal/vertical port sweeps and ephemeral port hoppingBehavioralfailed_auth_rateCount of failed SSH/RDP/IAM logins per windowDetects credential stuffing, dictionary brute-force, and lateral movementLeakage-Free Chronological Split with Zero-Day Holdout: Rather than using random $k$-fold cross-validation (which leaks contiguous multi-packet attack sessions across train and test sets), the 12,000-flow timeline is split strictly chronologically: the first 70% (8,400 flows) forms the training set, and the final 30% (3,600 flows) forms the held-out test set. Normalization parameters ($\mu_{\text{train}}, \sigma_{\text{train}}$) are fitted exclusively on the training window, and all 140 Zero-Day covert DNS/TLS exfiltration attacks are held out strictly in the test window.Stage 2: Baseline Formulation & Hybrid AI Ensemble DevelopmentDeterministic Baseline: Flags flows where volumetric or authentication Z-scores exceed $Z > 1.75$ or match static Sigma / YARA IOC rules.Supervised GBDT Branch ($P_{\text{sup}}$): Trained on labeled training flows to learn decision boundaries for known SYN/UDP DDoS and SSH/RDP brute-force attacks.Unsupervised Subspace Autoencoder Branch ($P_{\text{unsup}}$): Fitted strictly on benign training flows ($y_{\text{train}} = 0$). Projects the 7-dimensional normalized feature vector onto a 3-dimensional normal manifold $V_k$ and computes feature-weighted reconstruction error $E_{\text{recon}}(x) = \Vert{}(x - x V_k V_k^T) \odot w\Vert{}_2^2$, complemented by Isolation Forest scoring.Parallel Hybrid Fusion ($P_{\text{ens}}$): Combines both branches concurrently via $P_{\text{ens}}(x) = \max(P_{\text{sup}}(x), \, 0.94 \cdot P_{\text{unsup}}(x))$.Stage 3: False-Positive Reduction & Contextual Risk PrioritizationDynamic Time-of-Day Thresholding: Scales the anomaly decision boundary from 0.52 to 0.76 during business hours (08:00–18:00) when port entropy and login failures are within normal operating bounds:
$$\tau_{\text{dyn}}(t, x) = 0.52 + 0.24 \cdot \mathbb{I}_{\text{biz\_hours}}(t) \cdot \mathbb{I}_{\text{normal\_port\_auth}}(x)$$Threat Intelligence IOC Enrichment: Queries external IP and hash indicators against VirusTotal and MISP feeds, adding a +0.30 probability boost and a 1.25x risk multiplier on confirmed hits.Human-in-the-Loop Active Learning Feedback: Applies a -0.35 boundary suppression penalty to recurring benign administrative patterns (such as daytime or nightly server backups dismissed by SOC analysts) and logs them for incremental retraining.CMDB Asset Criticality Contextual Risk Scoring: Multiplies the calibrated threat probability $P_{\text{cal}}$ by the target endpoint's asset criticality weight (IoT_Smart_Bulb = 1.5, IoT_HVAC_Sensor = 3.0, Workstation = 5.0, App_Server = 8.0, Domain_Controller = 10.0):
$$\text{Risk\_Score} = \text{clip}\!\left( P_{\text{cal}} \times \frac{\text{Asset\_Criticality}}{10.0} \times 100.0 \times \text{TI\_Multiplier}, \; 0, \; 100 \right)$$
Alerts are routed into P1 Immediate Triage ($\text{Risk} \ge 50$), P2 Scheduled Review ($25 \le \text{Risk} < 50$), or P3 Passive Log ($\text{Risk} < 25$).Stage 4: Evaluation Metrics, Streaming Latency & SHAP ExplainabilitySub-Millisecond Real-Time Inference: Achieves 0.0020 ms per flow (~500,000 flows/sec per CPU core), compatible with real-time ONNX Runtime execution inside Apache Flink and Apache Kafka streaming pipelines.Explainable AI Triage: Computes local SHAP additive feature attributions for every alert so analysts immediately see which behavioral features triggered the detection.3.
